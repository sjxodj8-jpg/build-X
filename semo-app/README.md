# Semo App
## بناء التطبيق

لبناء التطبيق، اتبع الخطوات التالية:

1. قم بتثبيت Flutter من [هنا](https://flutter.dev/docs/get-started/install)
2. قم بتنزيل المشروع
3. افتح موجه الأوامر في مجلد المشروع
4. قم بتشغيل الأمر التالي:
   ```
   flutter build apk --release --split-per-abi
   ```
5. ستجد ملفات APK في المسار التالي:
   ```
   build/app/outputs/apk/release/
   ```

## تعليمات التثبيت

1. قم بتنزيل ملف APK المناسب لجهازك
2. قم بتثبيت التطبيق على جهازك
3. استمتع بالتطبيق!
